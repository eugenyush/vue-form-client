
# Vue Form Client - A Form Management Application

**Vue Form Client** is a web application built with Vue.js that provides an intuitive interface for managing and submitting forms. The application allows users to create, edit, and delete forms and their respective submissions, making it easier to handle form data effectively.

It is built using:

- **Vue.js**
- **Vuex** (for state management)
- **Axios** (for HTTP requests)
- **Bootstrap** (for styling)

## 👾 Features

- Create and manage multiple forms.
- Submit and edit form submissions.
- Responsive design optimized for desktop and mobile.
- User-friendly interface with real-time validation of form fields.
- Integrates with RESTful APIs for data handling.

## 📒 Process

I started by setting up the Vue.js project and configuring Vuex for state management. The core functionality revolves around creating and managing forms, which includes dynamic rendering of form fields based on user input.

I implemented Axios for handling HTTP requests to interact with a backend API, allowing users to submit forms and fetch existing submissions. The application is styled using Bootstrap, ensuring a clean and responsive design.

Additional features include real-time validation of form fields to enhance user experience and prevent submission errors.

**NOTE:** This application demonstrates the use of Vue.js and related technologies for form management.

## 🚦 Running the Project

To run the project in your local environment, follow these steps:

1. **Clone the repository to your local machine**:
   
   ```bash
   git clone https://github.com/eugenyush/vue-form-client.git
   cd vue-form-client
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Start the project**:

   ```bash
   npm run serve
   ```

   The app will run on [http://localhost:8080](http://localhost:8080).
